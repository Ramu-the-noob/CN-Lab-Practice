HTTP :
Step 1 : Open Wireshark.

Step 2 : Select the active network interface (Wi-Fi or Ethernet).
         Start Capturing Packets

Step 3 : Clear the browser cache.

Step 4 : visit http://neverssl.com or http://httpforever.com

Step 5 : Return to Wireshark Stop packet capture.

Step 6 : In the filter box enter http Click Apply.

DNS : 

Step 1 : Clear the DNS cache using the appropriate command for your operating system.

Step 2 : Clear the browser cache to force a fresh DNS lookup.

Step 3 : Open Wireshark Start Capturing Packets.

Step 4 : Open the web browser www.mec.ac.in

Step 5 : Return to Wireshark Stop packet capture.

Step 6 : Apply the display filter dns
